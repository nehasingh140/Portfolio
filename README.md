# Neha Singh — Portfolio

A single-page personal portfolio for a finance and analytics student, built with plain HTML, CSS, and JavaScript.

## Sections
- **Hero** — name, focus area, and a quick-stat strip
- **About** — short bio with a decorative trend-line chart (SVG)
- **Skills** — presented as a ledger-style table
- **Projects** — three sample finance/analytics projects
- **Contact** — email and social links

## Improvements made
- Added a responsive navigation bar using Flexbox, with a mobile hamburger toggle
- Used Google Fonts (Source Serif 4, Inter, IBM Plex Mono) for a clear type hierarchy
- Built the Skills section as a proper HTML table for a "ledger" feel fitting the finance theme
- Made the layout fully responsive with media queries down to mobile widths
- Added subtle hover/focus states and visible keyboard focus outlines for accessibility
- Included an inline SVG trend chart instead of a static image, so it scales cleanly at any size

## Running locally
Open `index.html` in any browser — no build step or dependencies required.
